# Legacy Admin UI (Deprecated)

> [!WARNING]
> **This package (`admin-ui`, the legacy Gogo admin console) is DEPRECATED.**
> All ongoing admin panel development, features, and deployments use the modern **`admin-dashboard`** SPA (`admin-dashboard/`).

## History

`admin-ui` was the initial Gogo-themed admin console. The console has transitioned to the modern PlanIQ-inspired architecture located in `admin-dashboard/`.

## Running the legacy console (if needed for reference)

```bash
cd admin-ui
npm install
npm run dev
```

For the active admin dashboard, refer to `admin-dashboard/` or run `make ui` / `make ui-build` at the root.
